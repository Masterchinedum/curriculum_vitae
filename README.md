# Chinedu Kingsley Okereke — CV Website

A [Next.js](https://nextjs.org) website that displays the CV and work profile of Chinedu Kingsley Okereke, Full-Stack & AI Systems Engineer.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the CV.

You can edit the CV content by modifying `src/lib/cv-data.ts` and update the page layout in `src/app/page.tsx`.

This project uses [Tailwind CSS](https://tailwindcss.com) for styling with a system font stack.
